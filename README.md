# Монитор расходов

Сайт для контроля платежей, договоров, актов, обязательств и отчётов организаций
по открытым данным [spending.gov.ua](https://spending.gov.ua). Работает на
GitHub Pages; данные по расписанию обновляет GitHub Actions.

## Как добавить или убрать организацию

1. Откройте вкладку **Actions** → «Обновление данных и публикация сайта».
2. Нажмите **Run workflow**, впишите код ЄДРПОУ в поле «Добавить организацию»
   или «Убрать организацию» и подтвердите.
3. Через несколько минут сайт обновится.

Другой способ — отредактировать список в `data/orgs.json`.

## Как это устроено

- `sync/sync.py` опрашивает портал и обновляет файлы в `data/`; запускается
  каждые 6 часов и при любом изменении в репозитории
  (`.github/workflows/sync.yml`).
- `index.html`, `app.js`, `style.css` — сам сайт. Он читает файлы из `data/`,
  а поиск выполняет запросами к порталу прямо из браузера.
- Первая загрузка организации — это история: в ленту попадают только записи,
  найденные при следующих проверках.

Файлы в `data/`, кроме `orgs.json`, создаются автоматически — вручную их
править не нужно.

## Ограничения

- У сайта нет входа: его и список организаций видит любой, у кого есть ссылка.
- Платежи загружаются за 92 дня до добавления организации и копятся дальше.
- Если у организации больше 5000 документов одного типа, их история берётся
  за последний год.

## Запуск на своём компьютере

```bash
python3 sync/sync.py            # обновить данные
python3 -m http.server 8020     # открыть http://localhost:8020
```
